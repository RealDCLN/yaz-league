League Rules & Scoring

How points are calculated and how check-ins are verified.

Country Check-ins

Each new country entered earns 100 base points. Subsequent check-ins within the same country yield distance-based bonuses.

Distance Traveled

Points are calculated per 100km traveled using straight-line spherical distance formulas between consecutive checkpoints.

Proof & Verification

All check-ins require GPS coordinates and proof photos submitted via the admin portal for official validation.
