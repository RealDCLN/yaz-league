Σύνδεση διαχειριστή

Μόνο ο διοργανωτής μπορεί να καταχωρήσει αποτελέσματα, να διαχειριστεί Χ2 και να τρέξει τις φάσεις.

Δεν έχουν ρυθμιστεί τα keys του Supabase στο js/config.js. Η διαχείριση απαιτεί ενεργή σύνδεση με τη βάση.

Λείπει το migration 005. Τα αποτελέσματα αγωνιστικών δουλεύουν κανονικά. Για Χ2, Patreon, ομίλους και Final-8 τρέξε supabase/migrations/005_winter_2026_27.sql στο Supabase SQL Editor.
